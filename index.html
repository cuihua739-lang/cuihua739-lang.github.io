Knowledge Distillation for Rank1 Reranking

Distilled a reasoning-capable reranker model into a lightweight student model using LoRA fine-tuning on Qwen2.5-1.5B. Trained on 385K samples, achieving effective knowledge transfer with only 0.59% trainable parameters. Reduced inference latency by eliminating test-time reasoning chains.
